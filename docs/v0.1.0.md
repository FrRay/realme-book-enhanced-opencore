# 「realme Book 增强版 OpenCore EFI」v0.1.0 首发说明

[简体中文 README](https://github.com/FrRay/realme-book-enhanced-opencore/blob/v0.1.0/README.md) · [English README](https://github.com/FrRay/realme-book-enhanced-opencore/blob/v0.1.0/README.en.md)

## 〓版本内容〓

本版本提供 realme Book 增强版的 OpenCore EFI、依赖准备脚本与双语安装文档。适配范围包括启动、核显与内屏、输入、无线、音频和电源管理。参考环境为 macOS Sequoia 15.8.3（24H241）与 OpenCore 1.0.8。

## 〓下载与安装〓

- `realme-book-enhanced-opencore-v0.1.0-efi.zip` 包含 EFI 模板及依赖准备脚本。
- `SHA256SUMS.txt` 提供发行包校验值。
- 项目首页收录快速安装、Windows 回退与适配过程。图形安装包及指定依赖由上游提供。

## 〓已知限制〓

触控板默认安装上游 2.9.1 版本，其表现可能与参考机使用的本地改版不同。具备匹配个人 EFI 时，可按安装说明导入原触控板组件。

# OpenCore EFI for the realme Book Enhanced Edition — v0.1.0

## 〓Release Contents〓

The initial release provides an OpenCore EFI, a dependency preparation script, and bilingual documentation. It covers boot, graphics and the internal panel, input, wireless, audio, and power management. The reference environment is macOS Sequoia 15.8.3 (24H241) with OpenCore 1.0.8.

## 〓Downloads and Installation〓

- `realme-book-enhanced-opencore-v0.1.0-efi.zip` contains the EFI template and dependency preparation script.
- `SHA256SUMS.txt` contains the release archive checksum.
- The project home provides a quick start, Windows rollback, and the build notes. The graphics installer and designated dependencies are obtained from upstream.

## 〓Known Limitation〓

The default touchpad option uses upstream 2.9.1, which may behave differently from the local build used on the reference unit. The installation guide covers importing a matching personal EFI.
